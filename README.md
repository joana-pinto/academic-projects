# Academic Projects

Portfolio of academic projects developed during my B.Sc. in Artificial Intelligence and Data Science at the Faculty of Sciences, University of Porto.

This repository brings together coursework and practical projects related to artificial intelligence, data science, machine learning, databases, algorithms and software development.

## Projects

| Project | Area | Description |
|---|---|---|
| [`hcc-analysis`](./hcc-analysis) | Machine Learning / Healthcare | Supervised machine learning project focused on hepatocellular carcinoma survival prediction using clinical data. |
| [`decision-tree-ai`](./decision-tree-ai) | Artificial Intelligence / Machine Learning | Implementation and exploration of decision tree models for classification tasks. |
| [`connect4-decision-tree`](./connect4-decision-tree) | Artificial Intelligence / Game AI | Connect Four project using decision tree-based logic and game strategy analysis. |
| [`connect4`](./connect4) | Programming / Game Development | Implementation of the Connect Four game. |
| [`maze-solver`](./maze-solver) | Algorithms / Search | Maze-solving project applying search and pathfinding techniques. |
| [`database-generator-shark-tank`](./database-generator-shark-tank) | Databases / Data Modeling | Database generation and data organization project based on Shark Tank-related information. |
| [`gui-shark-tank`](./gui-shark-tank) | Software Development / GUI | Graphical user interface project connected to Shark Tank data exploration or management. |
